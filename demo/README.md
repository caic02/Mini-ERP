# Base pública de demonstração

O arquivo `base-demonstracao.mdb` contém os cadastros fictícios de RH, benefícios, férias, contratos e medições, publicados com autorização do responsável pelo projeto.

Depois de preparar e abrir o programa, escolha **Abrir base existente** e selecione esse arquivo. Para testar com duas pessoas, copie a base uma única vez para o servidor e selecione o mesmo arquivo nos dois computadores.

**Acesso exclusivo desta cópia pública:**

- Usuário: `demo`
- Senha: `DemoMiniERP2026!`

As sessões foram removidas e as credenciais originais foram substituídas. O acesso acima é público e serve somente para a demonstração. O banco original não foi modificado; os históricos e os vínculos de autoria foram preservados.

Não envie futuras bases com dados reais para este repositório. O arquivo aqui representa uma cópia no momento da publicação; alterações feitas durante o uso não são sincronizadas com o GitHub.
